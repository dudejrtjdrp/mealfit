# 식사 개인화 서비스 — MVP 정보구조도 & 시안 화면 목록 (v1, 2026-09-15)

기획서 「외식·구매 식사 개인화 서비스」(송지선) 기준. 시각 버전: 아티팩트 "식사 개인화 MVP 정보구조도" (https://claude.ai/artifact/PnNp5qN6JzmhxNEVAz8J7R)

## 결정 사항
- MVP = 무료 구간 핵심 루프만 (온보딩 → 성향 분류 → 오늘 목표량 → 기록 → 주변 메뉴 판정 → 구매 가이드)
- 스택: Expo(RN)+TypeScript + Supabase. 주변 매장은 GPS + 카카오 로컬 API
- 식단 성향 분류: 규칙 기반 기본, API 키 있으면 AI 1회 호출. 같은 서술은 캐시(정규화한 서술의 해시 → 결과) 로 재호출 없음
- 시안 먼저 → 구현(Opus). 화면 ID(A1~F5)를 라우트·컴포넌트 이름으로 그대로 사용
- 제외: 유료 결제·AI 종합 피드백 실제 동작, 배달앱, 개인 식당 데이터, 사용자 제보·보정, 지도 뷰, 푸시, 친구·공유
