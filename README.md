# mealfit — 식사 개인화 서비스 MVP

내 건강관리 습관에 맞는 메뉴를, 지금 내 주변에서 찾아주는 앱. (창업공모전 출품작)

## 실행 (맥)
```bash
npm install
cp .env.example .env      # 키가 없어도 로컬 폴백으로 동작
npx expo run:ios          # 또는 npx expo start 후 Expo Go
```

## 검증
```bash
npm run typecheck
npm test
```
